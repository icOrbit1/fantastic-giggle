# fantastic-giggle

A beginner-friendly sentiment analysis application built with Python, Scikit-learn, NLTK, and Streamlit.

This repository contains:
- A reusable NLP preprocessing module
- A TF-IDF + logistic regression pipeline
- A validated CSV dataset loader
- Streamlit pages for dashboard, analyzer, batch prediction, dataset exploration, and model evaluation
- Automated tests for preprocessing, datasets, and predictions

## Overview

The app reads labelled training data, cleans and normalizes text, trains a logistic regression model, and predicts sentiment labels for new input. It exposes the workflow through a Streamlit web interface and keeps the logic modular so a real dataset can replace the demonstration sample.

## Features

- Text sentiment classification with Positive, Negative, and Neutral labels
- Probability output and confidence score per class
- Dataset validation for missing values and invalid labels
- Reusable NLP preprocessing with URL/HTML cleanup and negation-aware stopword handling
- Batch CSV analysis with download support
- Model evaluation on a held-out test set
- Beginner-friendly UI and documentation

## Installation

### Windows

```bash
cd fantastic-giggle
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Linux/macOS

```bash
cd fantastic-giggle
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run locally

```bash
streamlit run app.py
```

The app should open in your browser at http://localhost:8501.

## Retraining the model

The repository includes a small demonstration dataset in `data/sample_sentiment.csv`.

To retrain the model:

```bash
python -c "from src.train_model import train_model; train_model('data/sample_sentiment.csv', 'models/sentiment_model.joblib')"
```

To replace the sample dataset with your own labelled CSV, keep the required columns:

```csv
text,sentiment
"I really enjoyed the product.",positive
"The service was disappointing.",negative
"The update is okay.",neutral
```

Use the same training process with your file path. This project will reload the saved model only when the dataset hash matches, which helps avoid stale artifacts.

## Dataset format

The expected columns are:
- `text`: review, comment, or sentence
- `sentiment`: one of `positive`, `negative`, or `neutral`

The loader normalizes common label variants such as `Positive`, `NEGATIVE`, and `ok` to the canonical values used by the model.

## Deployment on Streamlit Community Cloud

1. Push this repository to GitHub.
2. Open https://share.streamlit.io/
3. Create a new app.
4. Select the repository: `icOrbit1/fantastic-giggle`
5. Use the branch: `main`
6. Set the app entry file to: `app.py`
7. Keep the Python version at 3.10 or later.
8. Deploy the app.

## Troubleshooting

- If `nltk` complains about missing resources, the app attempts to download them automatically. If that fails, use `python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords'); nltk.download('wordnet'); nltk.download('omw-1.4')"`.
- If the model fails to load, delete `models/sentiment_model.joblib` and retrain it.
- If batch upload fails, verify the uploaded CSV includes a `text` column and each row contains text content.

## Responsible use and limitations

- The example dataset is intentionally small and is not a benchmark dataset.
- Model confidence is an estimate based on the training set and should not be treated as a guarantee.
- The model must be retrained on representative labelled data before using it in production or high-risk settings.
